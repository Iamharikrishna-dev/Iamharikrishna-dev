## 🚀 Quick Start Guide

<div align="center">

### 🎬 Clone & Run My Projects

```bash
# LingoSound - AI TTS App
git clone https://github.com/Iamharikrishna-dev/LingoSound.git
cd LingoSound && npm install && npm run dev

# Blogiverse - Blogging Platform
git clone https://github.com/Iamharikrishna-dev/Mernblog.git
cd Mernblog && npm install && npm run dev

# Storyteller - Story Generator
git clone https://github.com/Iamharikrishna-dev/Storyteller.git
cd Storyteller && npm install && npm run dev
```

### 🧪 Running Tests

```bash
# 🎭 Playwright - E2E Tests
npx playwright test              # Run all tests
npx playwright test --ui         # Interactive UI mode
npx playwright test --debug      # Debug mode
npx playwright test --headed     # Headed browser mode

# 🌐 Selenium - WebDriver Tests (Java/TestNG)
mvn test                         # Run all tests
mvn test -Dtest=LoginTests       # Run specific suite
mvn test -Dsuites=regression    # Run by suite

# 🎯 API Testing
npm run test:api                 # Run API tests
npm run test:integration         # Integration tests

# 📊 Generate Reports
npm run report:html              # HTML report
npm run report:allure            # Allure report
```
